# Oneborg Q
Oneborg Q is a 1v1 only bot made in python.

* Starting with the [python example bot]("https://github.com/RLBot/python-example/blob/master/src/loadout.toml") and working from there.
* **No machine learning models used**, it will be hardcoded only.

# Origin

Oneborg Q is based on the original [Oneborg]("https://github.com/RLBot/RLBotPack/tree/master/RLBotPack/Oneborg/src") from the V4 botpack, it was the first bot I made that was able to compete with ReliefBot in a 1v1 and the first bot I made that could aerial as well.
